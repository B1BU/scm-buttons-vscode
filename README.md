# More Source Control Buttons

My personal fork of [Source Control Buttons](https://marketplace.visualstudio.com/items?itemName=tomblind.scm-buttons-vscode) by [Tom Blind](https://marketplace.visualstudio.com/publishers/tomblind). I made a lot of tweaks based on my personal preferences, check changelog for more details.

Add additional buttons to the source control panel. You can select which buttons you want enabled in the extension configurations.
